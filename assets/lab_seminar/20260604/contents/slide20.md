# 결론
+ Complex elliptic curve는 Line bundle의 section들을 통해서 projective embedding을 할 수 있다.
    + 이렇게 embedding된 object는 Weierstrass equation으로 표현된다.
    + projective space에서 irreducible equation으로 표현되는 점들의 집합을 \emph{projective variety}라고 부른다.
    + projective variety 중에서 group 구조를 가지는 것을 abelian variety라고 부른다.
+ Projective embedding 상에서 group 연산은 Line bundle위에 존재하는 section의 zero들이 어떤 관계를 갖는지에 달려있다.
    + 앞서 본 예시에서 degree 3 Line bundle위에 존재하는 section의 zero들을 다 더하면 합이 고정되어있다.
