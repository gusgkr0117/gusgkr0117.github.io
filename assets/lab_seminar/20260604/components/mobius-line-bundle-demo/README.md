# Mobius Line Bundle Demo

Interactive canvas component showing the Mobius strip as a real line bundle over `S^1`.

Use:

```html
<link rel="stylesheet" href="components/mobius-line-bundle-demo/mobius-line-bundle-demo.css">
<script src="components/mobius-line-bundle-demo/mobius-line-bundle-demo.js"></script>
```

Markup:

```html
<div class="mobius-demo" data-mobius-line-bundle-demo>
  <canvas data-mobius-canvas></canvas>
  <span data-mobius-angle></span>
  <span data-mobius-fiber></span>
</div>
```
